Customer Churn Dashboard Project Plan

Prepared by: Nondela
Date: June 2026


Problem Statement:
South African telecoms have long faced the problem of customer churn. The 2021 DataEQ Telecoms Index revealed that cancellation risk outweighed purchase interest across the industry, with Telkom showing the highest potential net churn. More recent reports from MTN, such as their FY 2025 Annual Report, stress customer retention and customer experience as strategic priorities, confirming that churn remains a critical issue for telecom operators today.

Objectives
•	Identify churn drivers: Analyze customer demographics, usage patterns, and contract types to reveal factors influencing churn.
•	Predict churn risk: Apply statistical and machine learning models to estimate the likelihood of customer churn.
•	Visualize insights: Build an interactive dashboard that highlights churn trends and risk segments.
•	Support business decisions: Provide actionable insights that help telecom operators like MTN design retention strategies.
•	Portfolio showcase: Demonstrate applied data science skills through documentation, coding, GitHub upload, and LinkedIn presentation.

Data Sources
•	Public datasets: Kaggle’s Telco Customer Churn dataset, which includes demographics, contract types, billing, and churn flags.
•	Synthetic datasets: Custom generated data that mimics MTN’s customer base (e.g., prepaid vs postpaid, usage patterns).
•	Company reports: MTN’s annual reports and investor presentations, which provide customer metrics such as ARPU, subscriber growth, and retention priorities.
•	Survey/social data: Insights from DataEQ’s Telecoms Index, which captures customer sentiment around cancellations and purchases.
Tools & Methods
•	SAS: Use SAS procedures for statistical modeling, regression, and data preparation.
•	R programming: Apply machine learning algorithms (e.g., logistic regression, decision trees, random forest) and build visualizations with ggplot2 and Shiny.
•	Data visualization: Create interactive dashboards to display churn trends, risk scores, and retention insights.
•	GitHub: Host code, documentation, and project files for portfolio visibility.
•	LinkedIn: Share project outcomes and dashboards to demonstrate applied skills to employers.
Deliverables
•	Customer Churn Dashboard: An interactive dashboard built in R (Shiny) or SAS Visual Analytics, displaying churn trends, risk scores, and retention insights.
•	Analytical Models: Predictive models (logistic regression, decision trees, random forest) with documented accuracy metrics.
•	Project Documentation: A structured Word/PDF report including problem statement, objectives, methodology, and findings.
•	GitHub Repository: Public repo containing code, datasets (or links), and documentation for portfolio visibility.
•	LinkedIn Showcase: A professional post summarizing the project, with visuals from the dashboard to demonstrate applied skills.
